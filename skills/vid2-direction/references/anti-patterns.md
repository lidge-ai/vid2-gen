# Defaults to reconsider → replacements

These are review prompts, not bans. A brand reference may justify any one of them; state the reason and inspect the result.

| Default | Replacement starting point |
|---|---|
| Gradient text on every card | Solid brand color, one 72–96 px headline and a 3 px rule; reserve gradient for one hero frame if the brand uses it. |
| Cyan-on-black neon everywhere | Pull 2 colors from the actual app and use one accent on a 70/20/10 background/type/accent balance. |
| Pure `#000000` and `#FFFFFF` everywhere | Try an off-black `#111827` and warm white `#F5F5F2`, then compare with brand assets. |
| Idle wobble on all layers | Hold labels still for ≥1.2 s; move one hero image 1.00→1.08× over 3 s. |
| Repeated centered cards | Alternate one wide product shot, one left-aligned claim, one close proof crop; keep a 5% safe margin. |
| RGB split on each cut | Use one 2–3 frame `rgbsplit` on the actual system-state change, or a clean hard cut. |
| Lens flare/light leak as filler | Use the interface highlight, a 0.2 s masked sweep, or a hard cut to real result. |
| Grid floors, particles, shockwaves | Show one real screenshot or captured action with a controlled 1.12× push. |
| Every element bounces | Use `out` ease on a 0.4 s entrance, `in` on a 0.25 s exit, and no extra bounce. |
| Every shot gets a dissolve | Use a hard cut for changed claim; one 0.3 s dissolve for continuity. |
| Imaginary UI with fake numbers | Record the real product; if a concept is illustrative, label it as a concept and keep claims factual. |
