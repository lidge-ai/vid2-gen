# Edit rhythm

Write a cut table with scene, visual change, intended emotion, phrase/downbeat, shot frames, and sound cue. Murch's ordering is emotion → story → rhythm → eye trace → screen plane → spatial continuity; its published percentages illustrate priorities, not measured quality weights. Cut when an idea completes or the next action begins. For captures, use the result appearing or command settling as a semantic marker; a blink is not an automated cut gate. Theory digest (`devlog/_fin/260928_film_grammar/003_theory_digest.md`).

Use a beat-length ladder as a rough cut: `0.5b`, `1b`, `2b`, `3b`, `1bar`, `2bar`. In 4/4, `1bar` lasts four beats. Try a short half-beat burst around one payoff, then restore a readable hold. Prefer a phrase turn for a major chapter change. Record any deliberate off-grid cut instead of silently snapping it. The observed references use this ladder but differ in pace: donald ASL 1.43 s, anabology ASL 2.47 s. ASL depends on shot-boundary detection and should be read alongside median and distribution. Reference measurements (`devlog/_fin/260928_film_grammar/001_reference_films.md`), ASL caveats (`devlog/_fin/260928_film_grammar/003_theory_digest.md`).

Check the final output against audio onsets as well as the authored beat grid. In the reference measurements, 58 % of donald's and 62 % of anabology's detected cuts fell within 50 ms of an onset. Our opencodex mix measured 7 % before WP2; the later authored beat-cut audit aligned 16/16 cuts on beat. Onset proximity and grid alignment are different measures. Use them as diagnostics, not a target that forces every cut onto a kick. Reference measurements (`devlog/_fin/260928_film_grammar/001_reference_films.md`), WP2 timing audit (`devlog/_fin/260928_film_grammar/010_timing_and_render.md`).

For new English text, estimate `holdSeconds = max(0.833, visibleCharacters / 17, words / 2.95)` from the moment every required glyph is legible. This is a conservative vid2 adaptation of subtitle research, not a rule for all advertising. Exclude entrance and exit animation from the hold. If image action competes with the claim, lengthen or split it. Theory digest (`devlog/_fin/260928_film_grammar/003_theory_digest.md`).

For a 30-second product trailer, one **house example** is 0–3 s: specific hook; 3–8 s: recognizable obstacle; 8–18 s: solution in use; 18–25 s: observable input → output proof; 25–30 s: brand and readable next action. Shift these boundaries to fit the destination, voice and song phrase. The sourced ad guides disagree on exact hook timing, so this is a planning sheet rather than a platform requirement.
