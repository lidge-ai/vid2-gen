**vid2 0.2.0** — launch films that look designed. A new motion-graphics engine lets words, glyphs, icons and rebuilt UI move on
their own inside the same `timeline.json`: kinetic typography with magic-move reflow, typing into a growing input, bar charts that count
up, rolling tickers, chips with connectors, `zoomfrom` / `iris` transitions, and sound effects driven by the animation.

**Film:** `ima2-launch.mp4` below (50 s, 1920×1080) was made with vid2 from [examples/ima2-launch](https://github.com/lidge-ai/vid2-gen/tree/v0.2.0/examples/ima2-launch):
real ima2-gen generations, a real capture of the ima2 web UI, synthesized music. QA pass, −14 LUFS.

**Install** (npm publication pending):

```bash
npm install -g https://github.com/lidge-ai/vid2-gen/releases/download/v0.2.0/vid2-gen-0.2.0.tgz
vid2 init kinetic-launch my-film
```
