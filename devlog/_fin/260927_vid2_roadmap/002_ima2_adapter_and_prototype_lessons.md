# 002 — ima2-gen adapter contract and prototype lessons

Source: read-only sol explorer survey of ima2-gen and its prototype video pipeline under scripts/recording/promo (2026-09-27). Anchors are ima2-gen paths.

## a. Optional ima2 adapter interface

**Keep vid2 usable without ima2.** When the adapter is enabled, invoke ima2’s JSON CLI for discovery and generation; use HTTP only where its route contract is clearer.

- **Discover and check readiness:** `ima2 ping --json [--server URL]` returns `{ok:true,base,version,pid,activeJobs,...}`. The CLI checks `IMA2_SERVER`, then the advertised server file (`IMA2_ADVERTISE_FILE` or `~/.ima2/server.json`), then `localhost:3333`; an explicit `--server` takes precedence. Follow with `ima2 capabilities --json --require-server` and `ima2 models --kind image|video --json`. Require `source:"server"` and a selected lane with `status:"ready"`; valid provider names alone do not establish readiness. `ima2-gen/bin/lib/client.ts:112`, `ima2-gen/bin/commands/ping.ts:18`, `ima2-gen/bin/commands/capabilities.ts:51`, `ima2-gen/bin/commands/models.ts:48`
- **Generate an image:** `ima2 gen PROMPT --model lane/model --size WxH --quality high --bg transparent|chroma-green -o PATH --json [--server URL]`. `--bg` is for core image lanes; transparent requests a PNG with alpha. Success is `{ok:true,requestId,elapsed,images:[{path,filename,requestedSize,actualSize}]}`. Treat `actualSize` and the saved file as authoritative: the prototype received approximately 1672×941 for a requested 1824×1024. Direct HTTP is `POST /api/generate` with `{prompt,provider,model,size,quality,backgroundPreset,requestId}`; a single result has `{image:dataUri,filename,elapsed,requestId,...}`, while a batch has `images`. `ima2-gen/bin/commands/gen.ts:65`, `ima2-gen/bin/commands/gen.ts:309`, `ima2-gen/bin/commands/gen.ts:370`, `ima2-gen/lib/generatePipeline.ts:671`, `ima2-gen/devlog/_plan/260927_promo_video/020_wp1_done.md:26`
- **Generate a Grok video:** `ima2 video PROMPT --model grok/grok-imagine-video-1.5 --duration 5 --resolution 720p --aspect-ratio 16:9 [-o PATH] --json`. One `--ref IMAGE` animates that opening frame; `--as-reference` makes it guidance instead. Core-lane success is `{ok:true,requestId,path,filename,elapsed,video,revisedPrompt}`. HTTP `POST /api/video/generate` accepts `{prompt,provider:"grok",model,duration,resolution,aspectRatio,requestId,sourceImage|referenceImages}` and streams `planning`, `submitted`, `progress`, then `done` or `error`; `done` includes `filename`, `/generated/...` URL, model and continuity metadata. `ima2-gen/bin/commands/video.ts:148`, `ima2-gen/bin/lib/videoMcp.ts:142`, `ima2-gen/bin/lib/videoMcp.ts:205`, `ima2-gen/routes/video.ts:652`
- **Continue and analyze:** `ima2 video continue PROMPT --video GENERATED.mp4 --duration 5 --json [-o PATH]` creates a *new* clip from the last frame with lineage; its JSON is the video `done` event, and `-o` downloads a copy. `ima2 video analyze GENERATED.mp4 --json` returns `{analysis,model,method:"first-last-frame"}`. Analysis infers motion from two frames; it does not inspect the whole timeline. `ima2-gen/bin/commands/video.ts:302`, `ima2-gen/bin/commands/video.ts:407`, `ima2-gen/routes/videoExtended.ts:442`
- **Extension needs a parent decision:** The present `ima2 video extend ... --video VALUE --json` sends `{prompt,videoUrl,duration}` to `/api/video/extend` and expects an immediate `url`. That route now requires `sourceVideoId` and returns **202** `{ok:true,requestId,sourceVideoId,workflow:"last-frame-i2v"}`. The synchronous provider-native route accepting `videoUrl` is `/api/video/extend/native`, returning `{requestId,url,filename,sourceUrl,duration,model}`. As written, the CLI extension contract and route disagree; vid2 should not rely on that CLI command until the owner chooses and repairs the intended extension semantics. `ima2-gen/bin/commands/video.ts:280`, `ima2-gen/routes/videoExtended.ts:253`, `ima2-gen/routes/videoExtended.ts:339`, `ima2-gen/routes/videoExtended.ts:349`

## b. Failure detection

Use exit status and typed `code`, then preserve `requestId` for inspection. Server absent is `SERVER_UNREACHABLE`/exit **3**; access or provider authentication commonly exits **4**; network/5xx **6**; timeout **8**; validation/4xx **5** when represented as an HTTP error. JSON `fail()` emits `{ok:false,code,message,...}`. For video SSE, inspect terminal `error` data `{error,code,status,requestId}`; the current consumer can collapse that to exit **1**, so do not infer its cause from exit status alone. `ima2-gen/bin/lib/output.ts:55`, `ima2-gen/bin/lib/output.ts:107`, `ima2-gen/routes/video.ts:159`, `ima2-gen/bin/lib/videoMcp.ts:164`

Distinguish server health from provider readiness: `/api/health` says the server is alive; `/api/models` reports `ready`, `disconnected`, `key-missing`, or `locked` with a reason. Grok OAuth without a session or with an expired unrefreshable session is `disconnected`; `grok-api` without a key is `key-missing`. `capabilities` can fall back to local metadata unless `--require-server` is set. `ima2-gen/routes/health.ts:51`, `ima2-gen/routes/models.ts:39`, `ima2-gen/routes/models.ts:139`, `ima2-gen/bin/commands/capabilities.ts:51`

## c. Prototype requirements for vid2

- **Recording:** CDP screencast ignored Playwright’s emulated DPR and produced 1440×900. Force Chromium’s device scale factor with `--force-device-scale-factor=2`, `viewport:null`, then assert the first frame’s expected 2880×1800 geometry. Acknowledge every screencast frame and retain timestamps and event marks. `ima2-gen/scripts/recording/promo/record.mjs:38`, `ima2-gen/scripts/recording/promo/record.mjs:51`, `ima2-gen/devlog/_plan/260927_promo_video/020_wp1_done.md:20`
- **Timing:** CDP supplies frames on change, so the attempted ffconcat duration path drifted. Quantize timestamp intervals to integer 30 fps slots, duplicate frames into a numbered sequence, and map events with the same rounding and a zero clamp. `ima2-gen/scripts/recording/promo/make_seq.py:15`, `ima2-gen/devlog/_plan/260927_promo_video/010_wp1_video.md:99`
- **Compositing:** Match window, mask, border, and shadow geometry exactly; zoom the *content* within a fixed frame. Preserve whole images with a blurred cover behind them when aspect ratios differ. Upscale stills before `zoompan` to reduce jitter. `ima2-gen/scripts/recording/promo/build.mjs:54`, `ima2-gen/scripts/recording/promo/mask.py:5`, `ima2-gen/scripts/recording/promo/build.mjs:102`, `ima2-gen/devlog/_plan/260927_promo_video/010_wp1_video.md:103`
- **Joins and encoding:** Normalize segments to the same dimensions, 30 fps/timebase, sample aspect ratio, pixel format, color range, and audio arrangement before `xfade`. For equal clips, total duration is `N·L − (N−1)·X`; compute join offsets from actual probed durations. JPEG-derived window footage emerged full-range `yuvj420p`, so convert it to TV range before joining. The 30-second edit pads segment edges before transitions and uses `+faststart`; its vignette/noise and bitrate settings are an example to expose as choices, not a proven universal preset. `ima2-gen/devlog/_plan/260927_promo_video/010_wp1_video.md:105`, `ima2-gen/scripts/recording/promo/build.mjs:166`, `ima2-gen/devlog/_plan/260927_promo_video/020_wp1_done.md:25`, `ima2-gen/scripts/recording/promo/build2.mjs:197`, `ima2-gen/scripts/recording/promo/build2.mjs:227`
- **Text, effects, and QA:** Animated `drawtext fontsize` segfaulted on ffmpeg 8.0.1; draw text at fixed size on a transparent layer and animate that layer. The prototype converts black-backed light leaks to alpha and mixes separate audio stems with compression, limiting, and loudness normalization. Verify codec, dimensions, duration, faststart, unexpected black runs, and a contact sheet; inspect frames at event seams. Isolate every mutable server path, especially its advertise and generation-log files. `ima2-gen/scripts/recording/promo/build2.mjs:30`, `ima2-gen/scripts/recording/promo/leak_alpha.py:1`, `ima2-gen/scripts/recording/promo/music.mjs:76`, `ima2-gen/scripts/recording/promo/qa.sh:6`, `ima2-gen/devlog/_plan/260927_promo_video/010_wp1_video.md:89`

## d. Porting judgment

Port the **timestamp-to-frame quantization and event mapping**, geometry/format assertions, ffprobe-based duration checks, black-run detection, and contact-sheet QA as small reusable operations. Adapt the mask and alpha conversion algorithms if vid2 needs those effects. `ima2-gen/scripts/recording/promo/make_seq.py:15`, `ima2-gen/scripts/recording/promo/mask.py:5`, `ima2-gen/scripts/recording/promo/qa.sh:6`

Redesign `record.mjs`, `build.mjs`, `build2.mjs`, and `music.mjs` around configurable inputs and a timeline: they embed one campaign’s URLs, selectors, fonts, paths, segment durations, captions, transition positions, and soundtrack. Preserve their filter techniques as examples. The open product judgments are whether vid2 should support native extension versus last-frame continuation, and which visual/audio effects deserve stable CLI options. `ima2-gen/scripts/recording/promo/record.mjs:6`, `ima2-gen/scripts/recording/promo/build.mjs:6`, `ima2-gen/scripts/recording/promo/build2.mjs:192`, `ima2-gen/scripts/recording/promo/music.mjs:6`
