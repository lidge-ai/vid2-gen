# 030 wp4: examples on demand — `vid2 example` and the vid2-examples skill

## Target behaviour

```text
$ vid2 example ls                    name, title, duration, needs, whether a workspace exists
$ vid2 example show opus-astra-paper manifest: summary, techniques, needs, steps, output, README path
$ cd "$(vid2 example new opus-astra-paper)"   copy sources into $VID2_HOME/examples/opus-astra-paper, print the path
$ vid2 example new vid2-intro --dir ./intro   copy into ./intro instead
$ vid2 example path opus-astra-paper          workspace path (no side effects); --source prints the packaged folder
```

`new` keeps `examples/workspace.mjs` semantics: repository sources overwrite their workspace copies; `media/`, `out/`,
`.work/` and `*.vid2cap/` in the workspace are kept. In text mode `new` and `path` print only the path so `cd "$(...)"` works.

## Manifest (src/examples/manifest.ts)

```ts
export const ExampleManifest = z.strictObject({
  name: z.string().regex(/^[a-z0-9-]+$/),          // must equal the folder name
  title: z.string().min(1),
  summary: z.string().min(1),                       // one sentence: what the film is
  durationS: z.number().positive().optional(),
  size: z.string().regex(/^\d+x\d+$/).optional(),   // "1920x1080"
  techniques: z.array(z.string().min(1)).min(1),    // "stage nodes", "springs", "web capture", ...
  goodFor: z.array(z.string().min(1)).min(1),       // requests this example answers: "paper cutout short", ...
  needs: z.array(z.strictObject({ tool: z.string(), optional: z.boolean().optional(), note: z.string().optional() })),
  edit: z.array(z.strictObject({ file: z.string(), what: z.string() })).min(1),   // where to change content for a new film
  steps: z.array(z.strictObject({ run: z.string().min(1), note: z.string().optional() })).min(1),
  output: z.string().min(1),                        // final video path relative to the workspace
});
```

`steps[].run` are the README's build-block lines after the `cd` line, verbatim and in order, without trailing `# comments`.

## Skill (skills/vid2-examples/SKILL.md)

Frontmatter description names the triggers ("make a video like", "example", "paper cutout", "launch film", "puppet", "keynote",
"start from a template"). Body: (1) a table mapping request shapes to an example or `vid2 init` template, using each
manifest's `goodFor`; (2) the fast route: `vid2 example show <name>` → `cd "$(vid2 example new <name>)"` → run the steps up to
the proxy render → edit the manifest's `edit` files for the new content → proxy, QA, final; (3) fallbacks: no music2 → drop the
audio block or use `vid2 audio synth`; no ima2 → `--placeholders` or the offline twin; missing logos/fonts in
claude-codex-dawn → substitute files at the paths its README names; (4) reuse notes per technique pointing at the example file
that implements it (key collector and seeded `rnd()` in opus-astra-paper, puppet helpers in claude-codex-dawn/puppets.mjs,
bar-synced cuts in ima2-launch, typed command and rolling number in vid2-intro). Every `vid2 X Y` mention passes the 020 lint.
