# Devlog

`_plan/` holds active implementation units and research. `_fin/` holds completed units, prefixed with the completion date (`YYMMDD_`). The current [vid2 roadmap](_plan/260927_vid2_roadmap/000_plan.md) defines work phases and their verification.

Record decisions and exact commands with observed results in the owning plan. Move a completed unit to `_fin/` after its implementation and checks are integrated. Keep current product behavior in `structure/`; the devlog is the decision and execution record.
