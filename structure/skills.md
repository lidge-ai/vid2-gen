# Packaged Agent Skills

Six Agent Skills ship in `skills/`: `vid2` routes by project state, `vid2-timeline` owns schema/time/error recipes, `vid2-direction` owns creative defaults and storyboard review, `vid2-capture` owns real UI sessions, `vid2-audio` owns beat/cue/mix guidance, and `vid2-cli` owns the validate→preview→render→QA loop. References are one level deep so an agent can load only the topic it needs. `skills/vid2-timeline/assets/timeline.v1.json` is a copy of the generated schema.

`node scripts/skills-manifest.mjs` copies that schema and writes `skills-manifest.json`. The manifest maps each packaged relative path to a SHA-256 and includes a stable aggregate hash for each skill. `src/skill/manifest.ts` resolves paths from the package root in both source and compiled installations. `src/skill/install.ts` compares content hashes and writes only changed files; its JSON result lists installed skill directories, changed file paths, unchanged paths, and a changed count. `--link` symlinks complete skill directories and refuses to replace an existing directory. `--tmp` uses the system temporary directory. The default target is Codex's user skill directory; `--agent claude|agents` selects the corresponding conventional location.

`node scripts/skills-lint.mjs` checks frontmatter name and description, relative Markdown links, mentioned CLI command names against `src/cli/registry.ts`, and packaged file presence. It requires the registry integration lane to register `skill`, `preview`, and `qa` before the full check can pass. The package build and published file list must include `skills`, `skills-manifest.json`, and `.claude-plugin`; integration owns package.json and CI wiring. The Claude plugin manifest lists all six skills; `skills/vid2/agents/openai.yaml` provides Codex display metadata.

The documented CLI is `vid2 skill list|path [name]|install [--dir <path>|--tmp|--agent codex|claude|agents] [--link] [--json]`. `path` defaults to the router. `list --json` returns `data.skills[]`; `install --json` returns `data.target`, `installed[]`, `changed[]`, `unchanged[]`, and `changedCount`. The primary cross-agent distribution route is `npx skills add lidge-ai/vid2-gen` after publication.
