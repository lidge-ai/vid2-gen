# Security policy

Please report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/lidge-ai/vid2-gen/security/advisories/new). Do not disclose an exploit in a public issue before maintainers have had a chance to investigate.

Include the affected version, a reproduction, impact, and any suggested mitigation. The maintainers will coordinate a fix and public advisory where appropriate.

vid2 executes local tools and reads user-supplied timeline paths. Treat media, timelines, capture logs, and provider credentials as sensitive; avoid uploading them with a report unless they are necessary and sanitized.
